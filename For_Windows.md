For the **3D demo**, you'll need Godot:

1. Download **Godot 4.5.2 Standard for Windows x86_64** from the [official download page](https://godotengine.org/download/archive/4.5.2-stable/). Choose Standard, not .NET.
2. Extract Godot and your shared project ZIP into ordinary folders.
3. Launch Godot, click **Import**, and select **`godot/project.godot`** inside your project folder.
4. Open the project and let Godot finish importing assets.
5. Press **F5** to run the demo.

This project also contains a LÖVE2D project. You **don’t need Lua, LÖVE, programming tools, or export templates** to play this version.

**Controls:** WASD/arrows move, mouse looks, **E** interacts, **Shift** runs, and **Esc** pauses.
