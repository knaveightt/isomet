# Archived title artwork

The current game renders a new original procedural splash in `visual.lua`. This archived image is no longer loaded by the game.

`miswander-title.png` is the selected title concept embedded on page 1 of the user-supplied `Miswander_Master_Plan.pdf` (Miswander Creator Master Plan, design draft 1.0, October 28, 2026). It was extracted without altering the artwork for use as the requested Miswander startup splash.

The PDF credits the concept to Brittney and John. Original upstream artwork authorship/licensing is not independently established here. This records provenance rather than claiming new ownership or license terms.

In-game pixel characters, props, gems and bitmap lettering are constructed in the project source.


## Current illustrated assets

The current scenery, terrain and traveler atlases are generated project artwork documented in [cartoon/README.md](cartoon/README.md), including the final prompts and built-in imagegen provenance. The source PNGs are retained intact and consumed through runtime atlas quads. Bridges, UI and other effects remain code-rendered.
