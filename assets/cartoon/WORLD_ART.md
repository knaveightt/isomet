# Flowing-world artwork

Original assets generated for Miswander with the built-in imagegen tool. The four user-supplied images in `guidance/` are art-direction references only; the game draws modular assets over real navigable terrain rather than displaying those screenshots as a board.

Final files:

- `kiln-landmarks.png`, `harbor-landmarks.png`, `snowfair-landmarks.png`, `orchard-landmarks.png`: fifteen distinct landmarks per world, sixty total. Each unchanged RGBA source is 1619×971. `cartoon_atlas.lua` records measured source rectangles, avoiding assumptions that generated sprite columns have exactly equal widths.
- `ground-materials.png`: 1254×1254 opaque atlas, four materials. LÖVE creates repeating texture Images in memory; original files remain unchanged.
- `world-backdrops.png`: 1254×1254 opaque atlas with four distant panoramas. Background landmarks are scenic, with no clickable rewards or hidden room details.

The game renders and is captured at 3840×2160, with native terrain meshes and a scaled, high-density HUD. This describes output resolution; it does not claim that every source sprite is a native 4K image. Generated source pixels are preserved rather than artificially enlarged on disk.
