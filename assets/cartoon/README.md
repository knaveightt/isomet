# Illustrated cartoon art — provenance and prompts

These project assets were generated with the **built-in imagegen tool** on October 31, 2026, then copied into this project. The three source PNG files are kept intact. `cartoon_atlas.lua` supplies read-only source rectangles; `cartoon.lua` creates cached runtime quads with linear/mipmap filtering. Atlas source rectangles are integration metadata, not destructively edited copies.

- [scenery-atlas.png](scenery-atlas.png): four themed buildings, tree, flowers, bench, chest and four guardians. RGBA, 1254 × 1254.
- [travelers-atlas.png](travelers-atlas.png): eight full-body traveler variants. RGBA, 1774 × 887.
- [terrain-atlas.png](terrain-atlas.png): four illustrated courtyard surfaces. RGBA, 1536 × 1024.

The user requested the cheerful, saturated, volumetric isometric visual genre associated with Township, Hay Day and Farm City. No assets were imported from those games. Source art is new project-bound generated imagery. The original pixel sprites have been replaced in character creation, gameplay and cinematic human characters; cinematic background geometry still uses the preceding low-resolution scene system.

The final generation prompt set is preserved below. All calls requested `transparent_background=true` and used the built-in tool, not the CLI fallback.
